## Shared contract

- Protocol schema2: `evaluator_revision='forward-paper-carry-v2'`, `behavior_revision='protective-carry-v2'`, `terminal_accounting='mark_open_positions'`, `management_behavior_sha256` equal to the canonical closed behavior document hash. Add these last three fields as optional omit-none fields to ForwardProtocol; schema1 requires all absent/None. Unknown, partial or mixed revision combinations are refused.
- The common `managed_behavior.py` is the single definition of behavior constants, strict typed `FixedDecisionV2`, decision encoding/digest and deterministic fixed decision/intent derivation. It may import the pure program module, but must not import strategy/driver/runner/coordinator. The owner must send exact public API signatures to other agents before they consume it.
- `FixedDecisionV2` has schema_version2, bar_index, decided_at, history_sha256, behavior_sha256, state, cause, target_fraction (Decimal or None), decision_sha256. Suggested closed states: long_target, cash_target, warmup, unavailable; causes: trend_above, trend_not_above, always_cash, insufficient_history, input_unavailable. Decide final exact names once and notify all owners. Digest excludes its own field and binds every other field. Parsing and re-derivation verify all fields.
- A valid LONG target must never create a reducing allocation rebalance. Only a valid explicit strategy CASH/SELL may propose reduction. Warmup, unavailable, calculation errors and deadline are not SELL causes. Entry is permitted only before E; a final positive target must not produce a new buy at E.
- The initial fixed study stops at E and carries remaining holdings at the final observed mark. It does not model a newly issued post-E management approval. Therefore no new automatic entry/reduction is dispatched from this study at E or after E without a separately supported authority path. Keep the strategy verdict distinct from execution blocking; do not report a valid SELL with missing authority as a model HOLD. Existing separately valid explicit/risk management routes are not automatically granted or deleted.
- Strategy/Runner owner can add defaulted `Signal` and `TickResult` metadata for typed decision state and fixed execution-block reasons if needed; agree exact fields with the driver owner. A blocked candidate must return a blocked result, not a model-hold claim. Metadata cannot authorize an order.
- New factory `tradegen-fixed-carry-v2` and `make_fixed_carry_driver` are selected only through the signed protocol revision. Closed factory/revision combinations must be independently verified by signer/review code. Keep the exact seven-field identity shape if sufficient; bind the new protocol and actual source closure. No bool/env activation switch or unsupported-branch fallback.
- Capture/decision schema2 is separate from existing review-request schema2. Capture V2 must bind the actual program artifact or its canonical program parameters and artifact hash so every typed decision is re-derived from the validated prefix. Share exact archive shape with the strategy owner before implementation. Valid current capture inputs remain strict; this work must not fabricate missing market observations or classify malformed evidence as normal unavailable.
- Carry simulation returns unissued arithmetic only. `strategy.py` must validate full inputs/registration/program, invoke the simulator, compute existing statistical/eligibility checks without lowering thresholds, and register the actual result. A manually constructed metrics/document object is not an issued result. Choose a new typed result or explicit versioned optional fields after agreement with the evaluator owner; legacy ValidationResult serialization/digest must stay unchanged.
- FIFO: buy fees enter lot cost; sell fees reduce proceeds; allocate released cost to 18dp downward and assign the last residual to the final quantity. Signed PnL uses a bounded new decimal-string codec; do not globally relax the old nonnegative serializer. Check `cash + marked_units - initial_cash = realized_net + unrealized_net`, avoid double-counting displayed fees. Base, double-cost, delayed and benchmark paths share the same terminal policy. Keep terminal quantities/cash/cost/mark/time/source and actual fees separate from valuation return.
- The final Coordinator slot starts before E for prefetch. After `_await`, use actual now to synchronously persist a P2 deadline event before Runner dispatch; a separate timer priority alone is insufficient. An explicit P2 writer receives no fabricated authority/facts/ledger references. Stable event/request IDs prevent duplicate application. Storage failure blocks dependent execution and is not a sell signal. The deadline bridge is only part of P2-integration; actual account/fill/order reconciliation remains pending.
- Existing GTC orders may fill after E. Tests must distinguish new create0 from late fills of existing IDs; do not claim E freezes total exposure. No deadline-generated cancellation authority.
