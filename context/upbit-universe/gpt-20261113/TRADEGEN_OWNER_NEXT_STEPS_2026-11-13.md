## 지금 필요한 상태 확인

PLB 승인 설계 §9.3의 step 0은 구현 전에 실제 운영 홈의 상태를 확인하도록 정했습니다.
§12.2 O14에 따라 S5가 `above`인지에 따라 추가할 하한 완화 기능의 범위가 달라집니다.
이 검사는 이미 PR23에 구현되었으며, 기존 승인된 코드 `0962e94`에도 있습니다.

1. 이미 `floor_state_check`를 실행했다면 **S1~S12의 결과 코드만** 이 대화에 알려주세요.
2. 미실행이라면 기존 승인된 Windows 저장소에서 `tools/floor_state_check.py`와 기존 venv가 있는지 확인합니다.
   이 검사를 위해 실행 중인 저장소를 최신 코드로 바꾸거나 재서명할 필요는 없습니다.
3. 실제로 사용할 state root와 독립 head root, 비공개 PLB의 시작평가액 `W0`, 보호 하한 `C`, 활성화 기준 `A`를
   PC에서 확인합니다. 입력 조건은 `0 < C < W0 <= A`입니다. 금액·경로·키를 채팅에 보내지 마세요.
4. 아래는 **자리표시자를 실제 비공개 값으로 바꿔야 하는 명령 양식**입니다. PowerShell에서 저장소 루트 기준으로 실행합니다.

```powershell
& .\.venv\Scripts\python.exe -X utf8 -m tools.floor_state_check --state-root "<운영 state root>" --head-root "<독립 head root>" --principal "<W0>" --floor "<C>" --activation "<A>"
```

5. 표시된 고정 결과 코드만 전달합니다. `unreadable`이나 거부 코드가 나오면 그것만 알려주세요.
   원본 owner log나 키 파일을 복사하거나, 확인을 통과시키려고 기록을 수정하지 마세요.

이 도구는 읽기 전용입니다. 종료 코드 0은 자료를 읽었다는 뜻이며, 실전 준비 완료를 뜻하지 않습니다.
이 초기 점검에 없는 신규 anchor·세션을 만들거나 서명할 필요는 없습니다.
