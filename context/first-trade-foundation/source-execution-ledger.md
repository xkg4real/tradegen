- Explicit Cloud proxy/CA routing preserves exact venue destinations, TLS,
  no redirects, disabled ambient settings and no direct fallback. Readiness
  revalidates current supplied policy without activating a route. Inquiry clock
  and exact private response bytes support a concrete read-only collector.
- Conservative Upbit KRW main-pocket collection preserves exact decimals and
  response digests, partitions closed-order creation windows and paginates only
  documented endpoints. It requires reviewed identity/retention/zero-inventory
  opening evidence, quiescent capture, exact fees and complete reconciliation.
- A strict private profile separates missing decisions from explicit zero and
  binds policy, current instrument rules, stable research terms and owner-context
  effectiveness. The default CLI reads no account or owner state and cannot
  activate a session.
- A prospective evaluator binds a predeclared strategy/capture implementation,
  profile, capital, rules and trial family. It checks causal decisions, exact
  cost/lot arithmetic, adverse ticks, delayed fills, cost stress and multiplicity.
  Genuine source/publication/implementation review remains external; computed
  metrics and hashes cannot issue execution permission. The evaluator currently
  supports Upbit KRW spot only. No real prospective study was run.
- The synchronous runner defaults to observation and requires explicit providers.
  Rehearsal uses dry adapters/isolated state. Controlled entries retain actual
  prepared-session/owner gates, stable identities, durable reservations and
  uncertainty reconciliation. Explicit protective exits remain available when
  research expires or the scheduler is stopped. There is no background service.
- Runtime/signer closure, acting/runtime scans and the new acceptance suite include
  both new packages recursively, including unused nested files.
- Independent read-only review found and corrected historical fills relabeled as
  the first day, fresh ticker metadata hiding an old trade price, native-currency
  profitability misapplied to KRW, and paper/profile capital applicability.
  Documented official endpoint and Windows locking contracts were checked.
