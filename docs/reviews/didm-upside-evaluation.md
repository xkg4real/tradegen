# DIDM 급등 포착의 전향 평가

TRADEGEN은 업비트 원화 현물에서 **급등 전에 실제로 관측할 수 있었던 신호와 호가**를 비교한다. 평가기는 오프라인으로 실행하며 주문을 보내지 않는다. 공개 저장소에는 실측 급등 포착률이나 순손익 결과가 없다.

## 관측 전에 고정할 값

연구 담당자는 아래 JSON의 기간, 시장, 임계값, 양방향 비용, 모형 버전과 SHA-256을 관측 시작 전에 독립 기록에 고정한다. 예시 시각과 비용은 합성 시험용이다. 실제 수수료·호가 충격 가정과 실제 모형 해시로 교체한다. 시간은 UTC Unix 초, bps는 1/100퍼센트포인트다.

```json
{
  "format":"tradegen-upside-terms-v1","market":"KRW-BTC","scope":"synthetic-study",
  "registered_at":800,"start":1000,"end":1120,"horizon_seconds":60,"max_gap_seconds":10,
  "early_seconds":15,"move_bps":"300","fee_bps":"5","slippage_bps":"3",
  "fixed_y_bps":"200","confidence":"0.75",
  "models":{"M":"1111111111111111111111111111111111111111111111111111111111111111",
            "B1":"2222222222222222222222222222222222222222222222222222222222222222"},
  "binary_arms":[]
}
```

- **M**은 사전 고정한 DIDM 포함 모형, **B1**은 가격만 쓰는 모형이다. 평가기의 `registered_features`에는 등록 원본의 변수 목록과 학습된 3개 클래스 사이에서 계수가 달라 예측을 바꿀 수 있는 변수 목록이 남는다. D1·D2·D3 중 가격 대조군 대비 유효한 추가 변수가 없으면 DIDM의 기여를 판정할 수 없다. M에 Q1도 등록했거나 다른 변수가 함께 달라지면 M−B1은 결합 효과다. DIDM만 추가했을 때도 그 결과는 해당 공통 표본의 수수료 차감 추정치이며 수익 개선의 인과적 증거는 아니다. 고정 기준선 **fixed**는 같은 진입 기회에 방향 예측을 추가하지 않고 사전에 정한 Y와 상태 조건을 적용하는 연구용 비교 정책이다. 실제 전략 수익을 복제하려면 별도로 원래의 진입 신호가 필요하다.
- 원본 호가 체인에는 같은 초에 수집한 최우선 매도·매수호가, 거래 참조가격 및 상태가 필요하다. 일별 호가 요약에는 매도호가가 빠진다. 원본 호가와 전향 예측 체인의 최종 해시는 독립 보관한다. 연구 조건은 정규화된 JSON의 SHA-256을 쓴다. 해시 체인만으로 기록의 외부 발행 시각이나 원천의 진위를 증명할 수는 없다.
- 실행 시 두 비교 모형은 단계 1 통과가 기록된 단계 2의 실시간 발행 원본과 매니페스트를 읽는다. 기존 유효 예측은 원래 만료 시각까지 쓸 수 있고, 자료 부족으로 새 예측을 내지 못했다는 발행 기록이 도착하면 기존 예측의 사용을 중단한다. 발행 시각과 실제 수신 시각이 모두 확인되며, 같은 초에 신호와 호가가 도착해 순서를 알 수 없으면 그 호가의 모형 판단을 보류한다.

## 산식과 지표 해석

서로 겹치지 않는 고정 구간을 같은 시장·시각에서 평가한다. 예정 종료 시각에서 최대 호가 간격을 뺀 시각 이후 처음 관측한 호가를 모든 모형의 공통 청산 기준으로 사용한다. 종단 호가까지 관측이 이어지지 않거나 신선한 양방향 호가가 없으면 구간 전체를 이유별로 제외한다.

급등 사건은 **먼저** 관측된 매도호가 저점과 **나중**의 매수호가로 양방향 비용 차감 수익이 기준 이상이 된 첫 순간이다. 저점이 같으면 첫 시각을 택한다. 같은 구간에서 여러 번 돌파해도 한 건이다. 저점 시각은 사후에 붙이는 사건 라벨이며 진입 알고리즘은 이를 읽어 매수를 결정하지 않는다. 구간 경계를 가로지른 움직임은 일부 놓칠 수 있다.

모든 비교군은 동일한 위험 상태와 고정 Y를 확인한다. 직전 정상 호가까지의 자료로 발행되어 목표 매도호가보다 먼저 수신된 신호가 필요하다. 가령 10초 호가 기반 신호를 11초에 수신하면 다음 정상 20초 호가에서 진입을 추정할 수 있다. 20초에 수신했다면 같은 초의 호가에서는 진입할 수 없다. 그때 신호가 만료·철회되었거나 상태가 막히면 해당 진입은 취소한다. 한 구간에서 최대 한 포지션이다. 단위 명목에 대한 비용 차감 수익률은 `청산 bid × (1−매도 슬리피지) × (1−수수료) / [진입 ask × (1+매수 슬리피지) × (1+수수료)] − 1`이다. 양쪽 모두 한 번씩 적용하고, 미진입은 현금 수익 0으로 기록한다.

| 결과 | 정의 |
|---|---|
| 재현율·조기 포착 | 급등 구간 중 임계 돌파 전에 가상 진입한 비율. 조기 기준은 저점 후 사전 지정 초 이내이며 저점 전부터 보유한 경우도 포함한다. 선행 진입 신호 수를 따로 제공한다. |
| 신호 지연 | 저점 이후 새로 수신한 유효 상승 예측을 돌파 전에 처음 사용할 수 있었던 호가까지의 시간. 고정 기준선에서는 진입 조건이 새로 열린 시각을 쓴다. 기존 상승 신호가 계속 유지된 경우는 새 탐지로 세지 않는다. 관측된 건수와 중앙값을 함께 제시하며 미포착은 재현율에 반영한다. |
| 거짓 진입·지연 진입 | 급등이 없던 구간에 진입한 건수와 비율. 급등이 있었지만 돌파 시점 이후 진입한 사례는 별도 집계한다. |
| 비용 차감 포착 | 전체 구간당·진입당·급등 구간당 고정 청산 순수익의 호가 기반 추정치(bps). 각 구간에 같은 단위 명목을 적용한 종가 기준 누적 순수익의 고점 대비 최대 낙폭도 bps로 제시한다. 구간 내 최대 낙폭과 복리 계좌 낙폭은 별도다. 수량이 미미하다고 가정한다. 호가 수량, 체결, 지연, 우선순위와 실계좌 순손익은 검증하지 못하므로 실제 체결 수와 손익은 null이다. |
| 동일 표본 비교 | 전체 유효 호가 구간과, 모든 모형이 모든 허용 판단 시각에 자료가 있던 공통 구간을 나눠 제시한다. 공통 구간 평균 수익 차이는 M−B1, 각 모형−fixed 단위다. 누락된 구간 수와 실제 평가 구간 수를 함께 읽는다. |

## 실행

```powershell
python -m tools.research.didm_upside_evaluation --terms TERMS.json --terms-sha256 TERMS_SHA256 --quotes QUOTE_ARCHIVE --quotes-head QUOTES_HEAD --archive FORECAST_ARCHIVE --forecast-head FORECAST_HEAD --output NEW_PRIVATE_REPORT.json
```

`--quotes`는 `quotes.jsonl`, `--archive`는 `prospective.jsonl`과 주소 기반 예측·매니페스트 파일을 포함하는 디렉터리다. 실행은 기존 결과 파일을 덮어쓰지 않는다. 원본 수량이나 거래소 자체의 호가 생성 시각을 제공하지 않는 기록기의 같은 초 표시는 로컬 수집 시각에 한정된다. 실제 주문 가능 수량을 검증하는 연구에서는 별도 호가 잔량과 시각 증거가 필요하다.

추가 비교군은 사전등록한 모형 해시와 함께 `--supplemental-signals FILE --supplemental-sha256 SHA256`으로 전달할 수 있다. 확인된 묶음이 여러 개면 같은 순서로 두 옵션을 반복한다. 파일 형식은 `{"format":"tradegen-upside-signals-v1","market":"KRW-BTC","scope":"…","signals":[…]}`이다. 각 신호는 `arm, market, model_sha256, as_of, issued_at, received_at, expires_at, direction, p_up`을 보존한다. 상승 확률이 없는 이진 규칙은 `binary_arms`에 미리 선언하고 `p_up:null`을 쓴다. 자료가 부족해 판단할 수 없는 갱신은 `direction:"unavailable", p_up:null`로 남긴다. 추가 파일의 SHA-256은 미래정보 차단을 입증하지 않으므로 실제 비교 전 원래의 발행·수신·입력 증거를 보존한다.

독립된 QUANTGEN 등은 표준 라이브러리만 사용하는 `evaluate(terms, quotes, signals)`에 같은 입력을 전달하여 결과를 재현할 수 있다. 각 호가에는 `market, scope, at, bid_at, bid, ask, last_trade, last_trade_at, same_second, blocked`가 필요하다. 금액과 확률은 십진 문자열이며 과거 매수 가능성을 추정할 때 확인되지 않은 위험·시장 상태를 허용으로 매핑하면 안 된다.

같은 호가 잔량·상태 조건으로 비교할 때는 연구 전에 `quote_gate:"corroborated"`를 추가하고, 외부 연구 검증을 마친 묶음만 `eligible_quotes`에 넣는다. 평가기는 각 항목을 원본 호가 시각·양쪽 가격·상태와 대조하며 원본의 진입 차단을 유지한다. 확인되지 않은 시점이 있거나 예정 청산 시점의 크기·상태가 불충분하면 해당 구간을 공통 평가에서 제외하고 사유를 센다. Python에서 직접 호출하는 경우 독립 검증기가 확인한 호가에만 `corroborated=True`를 지정한다. 이 모드도 체결 증거를 만들지는 않는다.
