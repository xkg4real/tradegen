# PR #79 요구사항 대조표 · 2026-11-28

**운영 판단은 실거래 보류다.** 원 PR의 `controlled` 경로는 보유 계좌의 연속 위험기록과 매도 권한을 입증하기 전에 주문 구성요소를 만들 수 있었다. 후속 변경은 런처, 코디네이터, 러너에서 그 경로를 차단한다. 모의 계좌에서 통과한 거래 경로와 연구 예측은 운영 계좌의 권한이나 수익성을 입증하지 않는다. [원 PR의 고정 버전](https://github.com/xkg4real/tradegen/tree/cd70bdd1dc0c3a920068337c8b1fadcb081ad95b) · [검토한 후속 커밋](https://github.com/xkg4real/tradegen/commit/171365fc81f4a4050e10c98f94c18426b701cdf1) · [후속 런처](../../tools/owner/live.py) · [보유 경계 회귀](../../tests/pr79_live_boundaries.py)

기준 사양은 PR #79의 기반인 `3ef3f9a`에 실린 소유자 결정이다. 표는 원 PR과 11월 28일 후속 코드의 차이를 포함한다. **구현**은 해당 오프라인 기능이 코드에 있다는 뜻이고, **모의**는 해당 동작이 합성 입력에서 검증됐다는 뜻이다. **부분**은 관련 코드는 있으나 행 전체의 완료 조건이 남았다는 뜻이다. **미완**과 **소유자**는 각각 구현·증거가 필요한 작업과 실제 결정·서명·관측이 필요한 작업을 표시한다. ## 접근법 A의 계좌·위험 규칙

| 규칙 | 판정 | 후속 코드에서 확인한 범위와 남은 증거 |

| BR-2 체결 목록 순회 | 구현·모의 | UTC 거래일 분할, 요청 상한·커서·구간 경계·중복 검사를 적용한다. 누락 페이지와 모순된 영수증은 거절한다. 실제 거래소 페이지 완전성은 별도다. |

| BR-5 수수료 | 부분 | 주문 상세의 수량·차감 수수료를 대조하고 체결별 증거 또는 배분값을 사용한다. 실제 myOrder와 REST의 수수료 대응, 예외 알림은 계좌 증거가 필요하다. |
| BR-6 티커 대조 | 부분 | 순회 전 티커와 가격·구간 증거를 읽는다. 불일치에서 재검사·영구 신규진입 차단·중복 없는 경보까지의 운영 연결은 미완이다. |
| BR-7 내 체결 대조 | 부분 | 주문·체결·공개 가격경로 검사가 있다. 거래별 공개 인쇄와의 완전 대조 및 `ask_bid` 의미에는 실제 양쪽 기록이 필요하다. |
| BR-8 분봉 사후 감사 | 미완 | 일봉 조회와 체결 순회는 있다. 분봉 확정 후 극값 불일치를 재검사하고 경보를 남기는 독립 감사 작업의 완료 증거가 없다. |
| BR-9 재검사·진입 차단·알림 | 부분 | 가드·중단 상태와 경보 구성요소는 있다. 해당 사건과 해제 권한, 재시작 복원, Telegram·Android 실제 수신까지 이어지는 경로는 미입증이다. OQ9의 모형 우위 기준도 미확정이다. |
| BR-10 오래된 체결과 최우선 매수호가 | 부분 | 정상 호가를 보존하고 관측에 계좌·시각·서명 Y를 결속한다. Y가 없을 때 신규매수를 허용할 근거가 없으며, 호가 괴리 단독으로 매도할 수 없다. |
| BR-11 서울 자정·22시 | 부분 | 계좌 평가 구간을 경계에서 자르는 모의 경로가 있다. 중단 복원 시각까지 모든 조각을 같은 거래 단위로 확정하고 양쪽 위험 상태를 이어야 한다. |
| BR-12 기한이 지난 경계 | 부분 | 지연·오래된 상태를 거절한다. 실행 중의 경계 실패와 꺼져 있던 구간의 복원을 구분한 운영 증거는 남았다. |
| BR-13 각 점의 보호 하한·일손실 | 부분 | 점별 평가와 기존 위험 가드가 있다. 외부 흐름을 조정한 하한과 실제 보호 하한을 함께 적용한 운영 구간 전체의 대사는 남았다. |
| BR-14 중단 확정 순서 | 부분 | 가드 일지에서 중단과 완료를 확인하고 응답 유실 후 복원하는 검사가 있다. 소유자 기록과 다음 운영 구간까지의 전달은 별도로 확인해야 한다. |
| BR-15 구간 중 한도 변경 | 부분 | 소유자 기록 변경·이전 상태 불일치를 거절한다. 한도 효력 시점에서 구간을 자르고 새 서명 시기의 상태로 넘기는 전체 경로는 미완이다. |
| BR-16 재시작·절전 공백 | 미완 | 재시작 신선도 검사와 안전 거절은 있다. 공백의 첫 30초, 중간 미판정 구간, 종점, 일자·한도 경계를 순서대로 복원한 운영 승인 증거가 없다. |
| BR-17 재구성 가능 기간 | 부분 | A1-4 N2에 따라 A0 확인 전에는 서버 UTC 날짜에서 7일 전인 날부터 보수적으로 거절한다. 보유·미체결이 없는 기준점 조건이 적용된다. 제7일 접근성 실측과 운영 재기준 설정은 남았다. |
| BR-18 조회 미완료 | 부분 | 미완 수집은 확정 계좌 프레임을 공급하지 않는다. 재시도·거래소 공용 IP 제한·모든 경보 채널을 엮은 운영 장애 경로가 남았다. |
| BR-19 롤백 방어 | 부분 | `classify_restart`가 일지와 이전 가드·기준점의 불일치를 검사한다. 복원한 외부 흐름과 보유 출처까지 같은 체크포인트임을 보이는 실계좌 증거가 필요하다. |
| BR-20 30초 제한별 처리 | 부분 | 정상 구간의 신선도 검사는 유지된다. 장기 공백의 관측·서명 시기·마지막 조각 예외를 모든 호출부에 연결해야 한다. |
| BR-21 입출금·체결 출처 | 부분 | 현금 흐름과 주문 상세를 검사한다. 개인 거래, 코인 입출금, 포켓 이동, 잔액 차이를 전부 분류·보관하는 운영 체인은 미완이다. |
| BR-22 조정 자산과 원금 보호 | 부분 | 기존 하한·일손실 검사와 별도 손실 예산 모의 계획이 있다. 미확인 차이의 원인 확인, 외부 흐름과 보호 최고점의 동시 이월이 남았다. |
| BR-23 앱·개인 수량 및 미체결 | 부분 | 체결 FIFO 계산과 앱 수량 상한 검사가 있다. 개인·앱 주문별 소유권을 재시작 후 독립 대조해야 한다. 출처 미확인 주문은 신규 진입 보류 대상이다. |
| BR-24 모든 관련 종목의 경로 | 부분 | 최대 네 시장의 동시 평가가 검증됐다. 수량·체결·입출금·잔차에서 영향을 받는 전체 종목과 공용 IP 예산의 실제 포괄 증거가 없다. |
| BR-25 연구 성과의 거래 귀속 | 미완 | 연구 영수증과 계좌 기록이 따로 있다. 모든 자금 변동의 출처를 보존하고 개인 거래가 전략 성과에 포함되지 않는 계좌 종단 대사가 필요하다. |
| BR-26 Y 상한·변경 이력 | 부분·소유자 | 선택적 `limit_set.bid_gap_fraction`과 D12 효력, 계좌·관측 시각에 묶인 정적 Y를 다룬다. 5%는 소프트웨어 최대값이다. 방향별 모형 Y는 연구 재생까지다. 검증된 실측·전향 시험·소유자 서명과 다음 관측부터의 운영 이력이 남았다. |

A1의 결과물은 모의 전송과 보유 평가 미리보기다. A2가 요구하는 운영 계좌·서명·거래 권한에는 `UpbitIntervalSource.execution_ready`가 거짓을 반환한다. 비교 근거는 수집기, 가격 평가, 커밋, 재시작 경로와 대응 테스트에서 볼 수 있다. | 개정 §3.12~3.15 | 부분·소유자 | Y는 기존 `limit_set`의 선택 필드다. 보호값 X·M·Md의 운영 권한은 `standing_armed`에 귀속한다. 별도 매매 권한이나 임의 상향 기본값을 만들지 않는다. N5 재확인은 미결이며 유니버스 보유 이월의 별도 평가·연구도 남았다. |
| 첫 거래 전 연구 및 운영자 확인 | 소유자 | 법규·적격시장, 승인한 코드 해시, 유효한 한도·전략·배포, 출처별 보유 대사, 해당 시장 증거와 실제 운영 환경 점검이 필요하다. KIS 현금주식·OKX 현물 수집기의 모의 통과로 주문 권한이 생기지 않는다. |

## 방향 모형 연구 §12와 Qlib

| 도구·연구 요구 | 판정 | 검증 범위와 남은 작업 |
|---|---|---|
| 가격·호가 기록, DIDM·QuantGPT 실행 기록 | 모의 | 가격과 수신 시각, 소스별·슬롯별 기록, 일별 호가를 합성 전송으로 검증했다. 실제 원본·수신 일지·비공개 계정의 수집 연속성은 아직 입증되지 않았다. |
| 시점별 특성, 적격 소스 | 부분 | 일별 DIDM 보고서의 버전 재선택, 최초 수신, V0 버전 필터, QuantGPT 봉투·수신 시각을 처리한다. 행 5(b)를 택할 경우 별도 cutoff-window 보고서도 검토해야 한다. DIDM 연구 이용권과 실제 적격 D3, 등록한 QuantGPT 모델의 Q1 전향 자료를 확인해야 한다. QuantGPT 신뢰도 자체는 방향확률의 증거가 될 수 없다. |
| 적합·동결, 예측·명세서 | 구현·모의 | 가격 달력 대비 누락, 특성 해시, 학습·평가 경계, 지정한 모델 버전·확률을 확인한다. 실제로 발행·수신된 예측은 필요하다. |
| 1단계 평가 | 구현·모의 | 같은 비중립 창의 B0·B1 비교, 유효 특성 전체 분모, 두 방향의 보정·반복 검사를 수행한다. B0나 특성 증거가 빠진 연구는 통과할 수 없다. |
| 2단계 호가 재생·이월 | 모의 | 1단계 최종 보고서와 연구 조건·모델·원 가격·예측을 결속하고, 고정된 경계 전의 자료만 비교한다. 종전 보고서는 원 증거로 재평가해야 한다. 실수신 호가·예측, 실체결 비용과의 비교는 남았다. |
| Qlib식 학습·후보 평가·내보내기 | 모의 | 평가 레이블 격리, 지연 도착 결과, 훈련 제외 구간, 두 모델 동결 후 동일 시장 비교, 배치 생성시각 및 최초 예측 보존을 검사했다. 과거 수익 검증이나 실전 승격 결과는 산출하지 않았다. |
