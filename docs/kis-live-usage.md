# KIS Live 사용 안내

TRADEGEN의 **KIS Live**에서 한국투자증권 실시간 체결·호가와 수신 표본 지표를 조회합니다. 업로드한 API 문서에서 채널·필드·종목 코드 규칙을 확인한 범위만 연결할 수 있습니다. 앱을 열거나 이 화면으로 이동하는 것만으로 연결하지 않습니다.

## Windows에서 연결하기

1. 기존 TRADEGEN 설치의 가상환경으로 앱을 실행합니다: `.venv\Scripts\python.exe main.py`.
2. **Settings**에서 KIS 설정 안내를 확인하고, 본인 PC의 기존 환경 설정 방식으로 접속 정보를 준비합니다. 이 화면에는 키·비밀값 입력란이 없으며 값을 표시하지 않습니다. 키를 대화나 GitHub에 올리지 않습니다. 실전·모의 환경에 맞는 이용 권한과 접속 정보가 필요합니다.
3. **KIS Live → 시장 → 접속 환경 → 시세 채널**을 선택합니다. 채널별 안내에 맞게 종목 코드를 입력합니다. 예를 들어 국내 KRX 주식은 `005930`, 미국 무료 시세는 해당 채널에서 `DNASAAPL` 형식입니다. 임의의 종목이나 시장 코드로 바꿔서 구독하지 않습니다.
4. **체결·호가 함께**가 활성화되면 문서에서 확인한 동일 시장의 두 채널을 한 연결로 구독합니다. KRX·통합·NXT를 서로 섞지 않습니다. 대응 채널이나 동일 종목 코드의 지원이 없으면 선택한 채널만 수신합니다. 이 옵션을 끄면 단일 채널만 연결합니다.
5. 연결 전 안내를 읽고 **연결**을 누릅니다. 공식 KIS 시세 소켓은 TLS로 암호화되지 않는 `ws://`입니다. 신뢰할 수 있는 네트워크를 사용하세요. 영구 앱 접속 정보는 고정된 HTTPS 인증 경로에만 전달하고, 소켓에는 메모리에 보관한 임시 승인값만 사용합니다.
6. **수신 중**, **마지막 수신 시각**, 오래된 자료·지연 시세 표시를 확인합니다. 끝나면 **중지**를 누릅니다. 시장·채널·종목을 바꾸거나 화면을 떠나면 기존 연결을 정리하며, 다시 들어와도 자동 연결하지 않습니다.

채널 목록이 비어 있으면 해당 시장·환경의 수신 형식이나 시각·가격 단위 검증이 아직 완료되지 않은 것입니다. 문서에 존재한다는 이유만으로 연결을 허용하지 않습니다. 현재 해외 선물·옵션의 일부 가격 단위·시각, 날짜·시각이 없는 일부 지표, 문서가 충돌하는 채권 호가는 확인이 필요한 범위입니다. 자세한 근거는 [API 계약 문서](kis-live-api-contract.md)를 봅니다.

## 화면 값 읽기

- **최근 가격 / 현재 지표**: 최신 체결 가격 또는 지수·지표값입니다. 지표를 실제 체결로 표시하지 않습니다.
- **호가 잔량**: 최우선 가격부터 최대 10단계의 매수·매도 가격과 잔량입니다. 스프레드는 최우선 매도 가격에서 매수 가격을 뺀 값입니다.
- **호가 불균형**: `(매수 잔량 − 매도 잔량) / 전체 잔량`입니다. 양수는 수신된 호가에서 매수 잔량이 더 많다는 의미이며 가격 상승 확률이 아닙니다.
- **표본 구간 수익률·VWAP·표본 수**: 현재 연결에서 최근 구간에 실제로 받은 자료만 사용합니다. VWAP은 수신한 체결의 거래량 가중평균이며 거래소 전체 또는 하루 전체의 VWAP이 아닙니다. 지표 채널에서 개별 체결이나 VWAP을 만들지 않습니다.
- **최근 체결**: 수신한 실제 체결 최대 20건을 최신순으로 표시합니다. 지표 전송은 체결 표에 넣지 않습니다.

연결이 끊기거나 자료가 오래되면 마지막 표는 회색과 **오래된 자료** 안내로 남고, 현재 지표는 `—`로 비웁니다. 휴장·거래 정지·권한 부족과 네트워크 장애는 모두 수신 중단의 원인이 될 수 있으므로 상태만 보고 주문 가능성을 판단하지 않습니다. 재연결 이후의 표본은 이전의 연속된 전체 거래 내역을 보장하지 않습니다. 끊김 횟수를 표시하고 누락된 체결을 가공해 채우지 않습니다.

화면 시각은 PC 시간대입니다. 원문에 날짜 없이 시간만 있는 채널은 수신일을 바탕으로 날짜를 추정하며 화면에 이를 명시합니다. 지연 채널은 최소 지연 시간을 표시합니다. 미국 무료 시세는 Nasdaq 계열의 일부 체결·호가를 전달하므로 전체 미국 시장 자료와 다를 수 있습니다. 권한이 필요한 실시간 채널을 지연 채널로 몰래 대체하지 않습니다.

## 연결 종료와 범위

연결 작업과 주기적 화면 갱신은 UI를 막지 않도록 실행합니다. 중지·화면 이탈·앱 종료는 수신 작업과 갱신 작업을 정리합니다. 종료가 확인되지 않으면 기존 연결을 유지해서 추적하고 새 연결을 막습니다. **종료 확인 필요**가 보이면 잠시 기다린 뒤 다시 중지하거나 창 닫기를 시도하세요. 창을 닫을 때도 수신 작업 종료를 확인합니다.

이 화면에는 주문·취소·계좌 체결 알림 구독이 없습니다. 파생상품·채권 시세가 표시되어도 해당 상품의 거래 허용이나 실제 계좌·자동주문 연결 완료를 의미하지 않습니다. 기존 자동매매의 소유자 서명, 실계좌 검증, 위험 한도, 전략 검증은 별도 조건입니다.

개발 검증은 가짜 세션과 자료로 수행하며 실제 KIS 접속 성공이나 시세 권한을 대신하지 않습니다. 법률·세무·투자 조언이 아니며 면허를 가진 자문가가 아닙니다.
