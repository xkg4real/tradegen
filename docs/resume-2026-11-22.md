## Independent implementation scope

1. The A0 public trade-list measurement probe, outside D14 and CAPTURE_FILES.
   It measures actual observed behaviour when an operator explicitly enables
   public network reads. Synthetic tests cannot certify exchange completeness.
2. A read-only DIDM input bridge for an explicitly supplied QUANTGEN snapshot.
   It preserves the original payload, provenance and knowledge time instead of
   rebuilding the ten existing provider connectors or using live credentials.
   Its output is research input, not model approval or execution permission.
