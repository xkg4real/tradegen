## Deviations from the rulings or the spec (with reason)

1. **Signatures carry the injected objects** (rulings 3.11 / S2): `market_vol_target(store, registry, clocks, market, decision_utc, knowledge_utc,
   estimator="sma20", book_ever_armed=False, *, rules=None, run_mode="live", vendor=None, stale_carry=())`, `hedge_state(store, registry,
   decision_utc, knowledge_utc, *, clocks=None, run_mode="live", rules=None)`. `rules` is a `MacroStore` or dict; default = the shipped store
   (lru_cache). `hedge_state(clocks=None)` treats every risk-model input as stale (conservative) and never raises. Section 4 of the rulings should
   read these forms.
2. **Stale-carry flags come from the caller.** M1 returns ingest `Flag`s and never stores them, so `market_vol_target(stale_carry=<flagged sessions>)`
   skips them and the window extends; any other missing session inside the window is `MissingInput("missing")` naming the session (F-3).
3. **VTResult / ComposeResult / HedgeState gained trailing default fields** (`series_id`, `books`, `label_status`; `reasons`; `notes`); positional
   construction preserved. `risk_layer(...)` returns exactly `{composed, gross, binding_factor}`; a scalar bound must name `bound_factor`.
4. **VSResult home** (integration ruling): `sleeves.VSResult(rule_id, market, family, revision, sigma126_ann, target_ann, value, status,
   exposure_basis="active", applies_to="", inputs=(), reasons=(), card=R03_CARD, factor="vs", book="specification", n_valid=0)` with status
   `ok | warmup | fixed_1.0 | not_run` is the one shape; the M2 stub (`sigma126`, `weight`, `insufficient_history`) is gone.
5. **`sma_vol` formula**: sqrt(var x days) instead of std x sqrt(days) (same number to 1e-16; bit-identical to the harness). T-VT-01's 1e-12 clause
   unchanged.
6. **Challengers are not registered in `risk_layer.ESTIMATORS`** (package A expected M3 to): `market_vol_target(estimator="ewma094")` must keep
   raising (T-VT-01 clause, item 25) until an R-30 counted revision can authorise the switch (M7). The registration point stays
