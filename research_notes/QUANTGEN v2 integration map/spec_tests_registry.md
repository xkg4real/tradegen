### B.2 `tests/macro_acceptance.py` [N] — suite module (one `tests()` export like the six existing suites, `run_all.py` L30-44)

```python
def tests() -> list[tuple[str, Callable[[], None]]]   # ("macro/<test_id>", fn); order = registry order
```
- A test is a zero-argument callable that raises on failure (runner contract, L47-55). No pytest, no fixtures framework (not in `requirements.txt`).
- Every callable is wrapped: `_wrap(row, fn)` runs inside `hermetic()` and `temp_state()`, maps `NotRun` to the third status (B.3), and refuses to run when `row.tier == "freeze"` outside the freeze job (B.6).
- Helpers that must not start with `test_` (gotcha E.15: `globals()` registration elsewhere).

### B.3 `tests/run_all.py` [E] — minimal extension

- Registration: two lines (`from tests.macro_acceptance import tests as macro_tests` … `[(f"macro/{n}", f) for n, f in macro_tests()]`) after `expansion`, L30-44 (do not move suites: cockpit must stay first, E.5).
- Third status: `except NotRun as exc: status, detail = "NOT_RUN", str(exc)`; `NOT_RUN` does not count as PASS and does not fail the run on its own; the summary prints `passed/failed/not_run`; exit code stays `0 if failed == 0 else 1`. Rationale: a REFDATA row must be reported as not run, never as passed (L5996) and must not block an exit whose fixtures the owner has not yet acquired (L6035).
- Result row gains `test_id`, `tier`, `runs_from` from the registry (keep the four existing keys; `qa/acceptance_results.json` stays the output).
- Optional filters (argv, no new dependency): `--tier fast|golden|freeze|all` (default `fast` → the existing 266-check behaviour and 155 s budget unchanged), `--milestone M<k>` (runs rows with `runs_from <= M<k>`, M7a < M7b), `--freeze-job` (the only flag under which a `freeze` row recomputes; otherwise it md5-verifies, B.6).
- Budgets (L5496): `fast` ≤ 10 min in total, `golden` ≤ 2 h; "default, judgment". The runner prints the per-tier total and warns above budget; it does not fail.

### B.6 Freeze tier (L5494, L5496, L2188, L4820)

## G. DO-NOT-BUILD items and invariants binding this area

- The repository stays read-only: no order, cancel, withdrawal, deposit-address or transfer path anywhere, test code included (T-RO-01, §10 item 21, L6235); test helpers and fixtures never contain the forbidden substrings in a way that would trip `tests/acceptance.py` `test_08`/`test_09` on runtime files (names containing `CANO` included).
- Freeze-tier results are never recomputed by `run_all.py` (L5494, L2188); the gate package changes only as a new version (L4828); nothing in the package is justified by the card it flips.
- No number is invented for a pending golden (§9.4, L5996); a golden is a reproduction, never a verdict (§9.3.3, L5982); the formal runs' comparison with research values is informative and never a reason to change the package (P11, L5706).
- A verdict within tolerance of its threshold is asserted as a class (L5499, L5737).
- Reference mode (`reference_only=True`) only from `tests/reference/` or `docs/`; `core/` cannot import it; such results never enter a book, card or artifact (L5992). Prohibited configurations it may compute: cap above 1 (item 2), DM gate at 0×, product stacks (item 31), the literal v1.2 ladder.
- Every acting input in a test fixture is read through `pit_value` with `available_at_utc <= decision_utc`; fixtures with pre-close close rows are refused (T-FIX-01); synthetic acting inputs are refused (T-SYN-01); the local Yahoo cache is never a manifest fixture.
- HALT is per book (C-1); tests assert scope, never an engine-wide halt (T-SCOPE-01, T-HALT-01).
- Composition is `min()`, nothing above 1.0, `composed >= 0.5 × vt` outside HALTED (T-CAP-01/02); a product-composed path raises even in tests.
- No new dependency (`jsonschema`, `arch`, `statsmodels`, `pytest`, `exchange_calendars` at runtime) without the owner; `core/` must not import them.
- Stochastic tests pass `seed`, `B`, `block` explicitly (L6018; `GATE["bootstrap_B"]` leak E.6); determinism per `reproducibility.determinism` (PCG64 via SeedSequence, spawned child seeds, BLAS threads 1, relative_tol 1e-12).
