## B. Final per-market x family weight table

### B.0 Rules, flags and the parse

Weight rules verbatim (R3:96): "W1: a coordinator ruling decides where it speaks. W2: otherwise, if the panels agree, that value. W3: otherwise the lower panel value, unless lab data at QUANTGEN net costs support the higher one (the gate is never loosened). W4: a cell only one panel reviewed keeps that panel's value, flagged * (it cannot feed any book until a card passes). W5: cells no panel reviewed keep the prior, flagged n.r. Proposed normalisation for macro R-15: base_weight = w / 3, so a weight of 3 equals 1.0x and no weight implies a multiplier above 1.0."

Parse rule for a view (applied to `final` only): `w` = the leading digit when `final` matches `^(\d)`, else `None`; `flag` = `*` when `final` matches `^\d\*`, else `''`; `base_weight` = `w / 3` when `w` is not None, else `None`; `w` in {0, 1, 2, 3} is asserted (observed: 0 x17, 1 x17, 2 x8, 3 x3, None x5), so `base_weight` in {0, 0.3333, 0.6667, 1.0} and never above 1.0. `n.r.` never occurs in `final` (it occurs in `professors` for 4 rows, B.5). The parenthetical after the digit is never dropped from display. `base_weight` is a labelled display column only: macro v2.0 defines sizing as `base_weight(m, f) = IV_m x 1/K_m` over admissible families with the 0-3 integers as "admissibility filters and display scores only" (SPEC:95, 662, 1712-1717), and R3:1309 (XS-21) files `w / 3` as a Proposal to the owner. Column meanings (R3:701): `alpha` = return source, `protective` = CARD-P protection claim, `screen` = exclusion rule on book membership gated as CARD-O against the unscreened book (CR-06, R3:46-48); a screen weight is never a multiplier.
