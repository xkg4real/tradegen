# 법규 재검토 잔여 쟁점 — 2026-11-06 KST

기준: PR12 병합 `21259f8`, 앞선 [47행 출처 검토](review_2026-11-06.md)의
미확인 항목만 후속 확인했습니다. 공식 웹 문서만 열람했으며 실제 거래소·증권사
API, 계좌, 키, 서명, 활성화 또는 주문을 사용하지 않았습니다.

## Korbit DigitalX mapping

**명칭 대응의 좁은 쟁점은 해결했습니다.** 기존
[Korbit 회사 소개](https://www.korbit.co.kr/company/)가
[DigitalX 공식 회사 소개](https://digitalx.miraeasset.com/company/)로 이동하며,
열람 가능한 연혁은 2026년 8월 법인명 변경, 9월 거래소 리브랜딩을 설명합니다.
이는 기존 `korbit` 식별자와 새 이름이 서로 무관한 거래소라는 오해를 해소하는
근거입니다. 내부 식별자, 도메인 허용 목록, 어댑터 또는 주문 권한은 바꾸지 않습니다.

공식 공지의 검색 색인은 법인명 변경일을 8월 11일, 서비스명 변경일을 9월 16일로
제시하지만, 직접 열린 공지 본문은 자바스크립트 화면 틀만 반환했습니다. 따라서
이번 변경의 직접 확인 근거는 회사 소개의 **월 단위 연혁**이며, 정확한 일자는
새로운 법적 효력일이나 코드 값으로 사용하지 않습니다.

- [법인명 변경 공지 위치](https://digitalx.miraeasset.com/notice/detail?noticeId=7qgqbKiTEexRwNWXMlWtgx)
- [서비스명 변경 공지 위치](https://digitalx.miraeasset.com/notice/?noticeId=1L240CRZhHXpBBCAa0OYSt)

[DAXA가 재게시한 10월 30일 FIU 목록](https://www.kdaxa.org/community/notice.php?boardid=notice&category=&idx=86&mode=view&offset=&sk=&sw=)의
본문은 Upbit, DigitalX, Coinone, Bithumb, Gopax를 포함한 28개 사업자를 적고
있습니다. 공식 [FIU 공지 목록](https://www.kofiu.go.kr/kor/notification/notice.do)의
검색 색인에는 같은 날의 원본 XLSX가 확인되지만, 직접 열람에서는 목록 본문과
첨부파일을 확보하지 못했습니다. **법인명 대응 확인과 규제기관 원본 첨부 검증은
다른 완료 항목**입니다. 새 사업자의 추가 허용이나 등록 유효기간을 추정하지 않습니다.

변경은 `KR-DOMESTIC-SPOT`의 출처 두 개와 이 기록 링크 추가입니다. `match`,
`treatment`, `requires`, 기존 검토 이력, `review_by`와 `affected_by`는 그대로입니다.
표 바이트가 바뀌므로 새 버전을 사용하려면 소유자의 rules 표 서명이 필요합니다.

## 첫 Upbit KRW 현물 경로에서 구분할 것

현재 `KR-DOMESTIC-SPOT.review_by`는 2026-11-22이며, 코드의 기한 판정은 그날까지와
그 다음 날을 구분합니다. 따라서 **11월 6~8일의 준비를 이 재검토 날짜 자체가
차단하는 것은 아닙니다.** 이는 다른 서명·계좌·시장·전략·위험 검사를 통과했다는
뜻이 아닙니다. 기한을 넘긴 신규 진입 거부를 피하려고 날짜만 연장하지 않습니다.

| 완료 조건 | 이번 확인 결과 | 남은 증거 또는 작업 |
|---|---|---|
| 국내 거래소 명칭 대응 | Korbit→DigitalX 회사 연혁 확인 | 내부 ID 변경이나 새 거래 지원을 이 근거만으로 수행하지 않음 |
| 최신 등록 상태와 적용 범위 | DAXA 재게시 본문의 현재 명칭 확인 | FIU 원본 첨부의 법인·서비스·수리/변경 상태 확인; 실제 계좌 제한 별도 |
| 현재 거래 가능 상품·주문 조건 | 이전 검토의 Upbit 공식 KRW 주문 정책 유지 | 해당 계좌의 인증된 현재 조건과 시세; 정적 법률 문서로 수수료·최소 주문·주문 가능 상태를 대신하지 않음 |
| 자기 자금·직접 경로·불공정거래 금지 | 기존 정책·행위 제한 유지 | 실제 전략과 운영이 해당 제한을 지키는지 구현 및 검토 |
| 11월 기한 갱신 | 미완료 | 행별 근거를 완료하고 새 검토 이력·기한을 제안; 변경된 표 소유자 승인 |

`KR-DOMESTIC-SPOT`는 네 거래소를 한 행으로 묶습니다. Upbit에 대한 일부 자료만
확인한 뒤 그 행 전체의 유효기간을 늘리는 것은 다른 세 서비스까지 재확인한 것으로
읽힐 수 있어 이번에는 하지 않았습니다. 분리된 행이 필요하면 중복 매칭·우선순위와
표 서명까지 검토한 별도 변경으로 처리해야 합니다.
